# GM 剧情工作台：文案组使用说明

日期：2026-10-19。入口：进入游戏按 `~` → GM 侧栏「剧情图谱」。无需切换正式游戏场景。

## 推荐检查流程

1. 默认进入「文案阅览」。左栏按类型、阵营筛选，输入事件 ID、标题、正文或页面 ID 查找。默认「全部配置」，搜索只作用于当前筛选；无结果时可点「重置筛选」。
2. 点击剧情：中栏列出配置页，右栏展示台词与选项。搜索命中正文时会定位第一处命中页。页目录可按 ID、正文、选项过滤；「查下一处」在本段匹配页间循环。
3. 上一页 / 下一页 / 输入页码跳转都是**配置页序**，不是实际剧情路径。互斥分支也列出，不能视为每页已读或可连续播放。只为已有 `nextPageId` 提供显式跳转定位，不推测选择对应的去向。
4. 正文支持独立字号调节；「页面配置 / 分支条件」可展开查看原始条件、检定及结果。完整条件组语义仍保留在原图模型，不另建剧情解释器。
5. 「关系图」保留跨事件连线、证据、缩放和平移。「返回上一处」恢复节点、页面及筛选，避免查看前置后找不到原阅读位置。
6. 发现错字、错误分支或表现问题，点「复制问题定位」，把模板贴给程序并补充问题、预期和实际使用的检查方式。模板包含事件、页面、配置序号、会话来源与当前页配置；不包含存档导出。

## 两种试播不能混淆

| 操作 | 能检查什么 | 不能证明什么 |
|---|---|---|
| 本页样式预览 | 正式面板里的排版、文本和资源 | 忽略页面条件；选项不结算；不能证明自然可达 |
| 从头分支试播 | 在独立内存副本里按条件、选择和检定推进 | 不写正式进度；不代表正式存档中的完整自然通关 |

- 真实咖啡制作步骤仍会停止并报告，不创建订单、不伪造交付成功。
- 建设闸门和舞台占用仍由现有宿主检查，界面不提供一键解锁或强制放行。
- 正式会话存在时，状态来自正式会话，试播使用其可复制的测试数据；无正式会话时是默认测试值，不是玩家当前数值。
- 配置浏览、静态验证、样式预览、独立分支试播、正式自然通关是不同验收层级。
- 「刷新当前快照」不重启剧情，不把磁盘新表热替换到运行中的会话。改表后仍走现有 Excel → 官方 Luban 管线，并按正常流程重新载入会话。

## 快捷键与布局

- `Ctrl+F`：聚焦剧情搜索。
- `Alt+←`：返回上一处。
- `PageUp / PageDown`：按配置顺序翻页；输入框编辑时不触发。
- 图内滚轮：缩放；右键 / 中键拖动：平移；`F` 或「适应全图」：全图。
- 小窗口隐藏独立页目录，保留正文区的搜索、页码与翻页入口；过小窗口使用外层滚动，不继续挤压正文。
- 上方预览与翻页按钮固定，长正文独立滚动。

## 实现边界

共享 `NarrativeRelationshipGraphView` 的 `Writer` 分部管理界面和临时浏览历史。`StoryContentBlock` 的可读字段是从既有配置派生的显示数据，不是新的表字段、源文件或运行时状态。原 `Text` 保留兼容及完整证据复制。没有更改 Excel、生成 JSON、存档结构、正式演出 Prefab 或 Build Settings，也没有新增测试场景。

演出与 GM 回归仍复用 `Assets/Scenes/PresentationDebugScene.unity`。本轮实际测试结果以完成后的交付说明为准，不沿用旧交接中的通过数量。
