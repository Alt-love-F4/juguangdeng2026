# 拉花杯与拉花

## 玩家操作

1. `CoffeeShop` 制作区域右侧原拉花入口位置现在放置 600 ml 拉花杯。
2. 将牛奶或热牛奶加入壶中，点击拉花杯，将牛奶等量转换为奶泡，保留温度与原料来源。
3. 拉花杯始终禁用玩家右键倾倒，无论装的是牛奶、清水还是奶泡。加入牛奶不会自动打奶：必须点击拉花杯转换成奶泡，之后才允许拖动；空壶或只有未打发牛奶时不能被玩家拖起。
4. 将装有奶泡的壶拖到同区域且已有饮品液体的杯子上松手，进入已有拉花工作台；空杯拒绝使用奶泡，不要求杯子预先放到出餐区。
5. 仅在杯面有效区域按住左键绘制时，按实际接受量扣除壶内奶泡并加入绑定杯子。默认每秒 6 ml（由8降低25%），线宽和流量倍率会影响消耗。
6. 工作台实时显示「已用奶泡」「壶内剩余」，奶泡耗尽或杯子装满后停止绘制，不溢出、不扣除未接收的奶泡。每个参考图案实时显示拟合百分比，金色「最佳」独立于手动选择的参考高亮。
7. 「重新绘制」及 R 键清除图案和本轮倒入目标杯的奶泡，不退回壶；杯内原有液体/奶泡保留，丢弃量计入废弃记录。返回或取消保留当前杯内奶泡，不返壶。
8. 拉花液面取目标容器实际液面颜色，倒入/重绘后同步；界面底色再乘亮度 `0.65` 加深，不改变真实杯子颜色和白色奶泡。完成后杯内成分显示 `拉花XXML·图案XX`，未知图案显示“未识别”。饮品配方中的奶泡/奶沫显示为“拉花”，要求完成绘制，不限制具体图案或拟合度；库存仍保留奶泡原料，稳定ID保持 `milkfoam`。

## 参数调节

场景对象 `BuildingViews/floor1/Cafe/Counter/LatteArtBench/Background` 的 `FreeCafeLatteArtBench`：
- `Foam Ml Per Second`：基准奶泡消耗，当前6；越小消耗越慢。
- `Liquid Color Brightness`：仅拉花界面液体底色亮度，默认0.65；越小颜色越深。
- 实际每秒消耗 = 基准消耗 × (`Pour Rate` / 5) × (`Brush Radius` / 0.018)²，所以滚轮加粗也会增加消耗。`Pour Rate` 与 `Brush Radius` 位于液面 `LatteArtPrototype`。

## GM 与资源

- 玩家 HUD 按钮及世界旧入口已移除；`~` 打开 GM，在诊断分类使用「拉花快捷入口（GM）」。此入口绑定出餐杯且不消耗原料，仅用于测试。
- 旧入口规格保留用于存档兼容，加载旧制作存档时移除旧入口并补齐拉花杯。
- 独立 Prefab、美术注册和场景对象由 `Tools > Free Cafe > Install Milk Pitcher` 增量安装，保留现有场景布局和其他 Prefab。
- `empty.png` 为生成原图；`sprite.png` 为移除生成棋盘格背景后的透明游戏精灵，原图不覆盖。
- 权威会话包含目标杯、来源壶、累计实际奶泡用量；普通拖动、清空、加料与倾倒不能修改正在拉花的容器。

## 回归

- CoffeeShop 的 `tool.milk-pitcher` 场景实例缩放为 `(0.65,0.65,1)`，仅影响该实例；Prefab 默认缩放保持1。运行时接管实体保留世界尺寸，因此其根局部缩放会包含原场景分组的倍率。
- 拉花杯接入 `OrthographicGlassCupPresenter`，液面与壶身共用根变换。玩家输入与表现分离：玩家不能倾倒，但外部脚本强制调用 `PresentPour` 或接收液体时仍显示实际液面；`PresentPour` 只控制表现，不扣库存。权威 `PourLiquid` 对拉花杯源始终拒绝。液体视图尺寸为0.82×1.02本地单位，不再次乘根缩放。
- EditMode：`FreeCafeMilkPitcherTests`，涵盖体积守恒、温度、容量、耗尽、取消、令牌、锁定、存档及迁移。
- PlayMode：`FreeCafeMilkPitcherPlayModeTests` 与 `FreeCafeProductionPlayModeTests` 的拉花杯用例，验证场景缩放、液面、真实拖杯、GPU绘制、耗奶泡守恒、用量UI、杯满/耗尽、重画与取消。
- 不创建新的演出场景、Canvas 或输入系统。
