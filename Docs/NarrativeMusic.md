# 结局与长剧情配乐

## 配置与行为

- 配置资产：`Assets/Resources/GameAudioCatalog.asset`，Unity 菜单 `Tools > Audio > Game Audio`。
- `music.ending.<endingId>`：16 个正式结局的独立音量、淡入和曲目配置。ResultPanel 打开/重新显示时覆盖音乐，隐藏、关闭或销毁时释放；未知调试结局回退到《回忆》。普通结果、保存成功不更换音乐。
- `music.conversation.<presentationKey>`：61 个已阅读文本并人工初配的长剧情。NarrativePresenter 在事件级启动，跨翻页、选项及插入信件持续播放；完成、取消或宿主销毁时恢复当前场景音乐。不是等玩家停留一分钟后才启动，也不依据运行时关键词猜测情绪。
- 配置中的页面 `bgmOverride` 仍然优先，可用于个别页面的明确演出要求。
- 恢复使用现有音乐请求栈：恢复当前的场景曲目，并非恢复之前的精确播放时间。
- `Tools > Audio > Add Missing Narrative Music` 只补缺失配置，不覆盖已调好的条目；初始映射位于 `Assets/Editor/Audio/NarrativeMusicSetup.cs`。
