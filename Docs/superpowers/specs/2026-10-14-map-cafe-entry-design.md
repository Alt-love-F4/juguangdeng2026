# 地图地点详情与咖啡馆入口 Spec

日期：2026-10-14  
状态：需求已确认，待工作 Agent 实现

## 目标

为新手教程验证提供一条稳定入口：玩家从城市地图点击咖啡馆，打开地点详情并选择进入，随后进入现有 `CoffeeShop` 场景。暂未配置功能的其他地点继续显示在地图上，但点击时不打开行动详情。

## 已有实现

- 地点由 NCS `TbNcsMapPosition` 配置；当前 `cafe` 已配置图标资源 `Art/Map/Locations/location_03`，但 `defaultAction` 为空。
- `MapSceneController.OnPositionClicked` 当前对所有地点执行统一聚焦与详情显示。
- `MapSceneController.StartCafe` 已有入口，委托 `DayFlowController.StartCafeFromMap` 或加载 `CoffeeShop` 场景。
- 正式 `MapPanel` 使用 `MapActionDetailsView`；其现有 NCS 行动卡片不应承担咖啡馆场景入口的行动结算。

## 行为要求

1. 地图上所有已配置地点图标保持显示，不因本次改动隐藏、删除或重排。
2. 点击非 `cafe` 地点时，保留现有地图聚焦/镜头移动表现，但不打开行动详情弹窗，也不执行地点行动。地点已有 NCS 行动配置暂时保留，后续功能启用时再恢复详情入口。
3. 点击 `cafe` 地点时显示咖啡馆详情。详情中有清晰的“进入咖啡馆”操作；点击后复用现有 `StartCafe` / `DayFlowController.StartCafeFromMap` 链路，进入 `CoffeeShop`。
4. “进入咖啡馆”是场景导航，不是 NCS 行动：不检查或消耗行动点、物品，不触发 NCS 行动结果。
5. 保留现有首日地图引导约束、DayFlow 状态校验、加载转场及咖啡馆内部教程流程；地图入口不得重置玩家状态或重复初始化新游戏。

## 范围外

- 不修改其他地点图标、坐标、文案或 NCS 行动数据。
- 不实现其他地点功能，不调整咖啡馆内部玩法/教程，不改场景内容。
- 不改行动点规则、日流程、存档格式或地图视觉布局。

## 验收标准

- 地图中所有现有地点图标仍可见。
- 点击市场、图书馆及其他非咖啡馆地点后，地图可按原行为聚焦，但行动详情不出现，也没有行动被执行。
- 点击咖啡馆后出现详情和“进入咖啡馆”操作；点击该操作后切换至 `CoffeeShop`。
- 进入前后行动点数不变；不要求玩家先有行动点，也不扣除物品或触发地图行动。
- 首日新手引导中仍只能通过咖啡馆入口进入；正常 DayFlow 和独立地图加载路径均不回归失败。

## 验证

- 增加或更新地图 PlayMode 回归，覆盖非咖啡馆不显示详情、咖啡馆详情提供进入操作、进入操作不调用 NCS 行动结算。
- 在正式 `Map` 场景手动验证点击咖啡馆并进入 `CoffeeShop`，确认行动点未变化；同时确认其他地点图标仍在且点击不弹详情。
