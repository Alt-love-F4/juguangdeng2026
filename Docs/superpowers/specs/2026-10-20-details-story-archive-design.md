# 详情面板剧情档案设计

日期：2026-10-20
状态：待审核

## 目标

在玩家详情面板中提供只读剧情档案，复用 GM 剧情图谱已有的 NCS 文案。列表按根事件聚合：一个根事件只占一个入口，打开后将对话页按配置顺序合并阅读，不把十余个 ConversationPage 拆成十余个列表项。

只有可由当前正式会话证明已发生、正在播放、已排队或当前可请求的内容才向玩家开放。无法确定解锁状态时隐藏内容。

## 交互

- 新增“剧情”页，保留详情面板原有三页。
- 双栏布局：根事件列表和连续阅读区。列表按现有剧情分组/顺序组织，不显示逐页目录、条件诊断、关系连线或 GM 试播控件。
- 已解锁根事件显示正式标题；选择后按 NCS 页面顺序展示 `NarrativeRelationshipGraph.Content` 的 `BodyText`，保留说话者、叙述和选项文案，不显示技术诊断文本。
- 未解锁项只显示通用锁定占位，不显示标题、事件 ID、日期、路线、页数、摘要或正文；不提供会泄露内容的搜索、悬停提示或可访问名称。选择锁定项不会打开阅读区。
- 无可展示内容时显示中性空状态；运行时未就绪时不从静态配置推断解锁。

## 数据与解锁边界

1. 内容复用 `NarrativeRelationshipGraph` / `StoryContentBlock`，只读正式 `NarrativeRuntime.Configuration`。无正式 controller 时所有事件锁定。
2. 只收录 NCS 根事件。不把 OpeningPresentation 当作 Event 历史，也不从同名 ID 推断播放记录；结局面板与调试节点不在范围内。
3. 根事件满足任一现有证据时解锁：`State.HasHappenedEvent` 为真、事件正在播放、事件已排队，或 Immediate / MapAction 事件的只读诊断 `ExplainEvent` / `ExplainMapActionEvent` 返回 `CanRequest`。
4. 显式锁定、施工阻塞、条件不满足、诊断异常、其他无法可靠预检的入口类型及运行时/存档缺失均按锁定处理；不得运行入口、执行结果、模拟条件或写 NCS 状态。
5. 解锁粒度为根事件。解锁后该事件全部配置页面均可阅读，包括条件页、互斥分支和未播放后续页。系统没有逐页阅读历史，因此不把档案宣称为已读记录，也不新增逐页持久化状态。
6. 不新增 Excel 表、Luban 字段、NCS 事实、存档字段或平行叙事系统。详情面板只消费展示快照；锁定内容不得进入可见 UI 文本或交互式可访问描述。

## 实现边界

- 扩展 `DetailsPanel.Page`、PSD Prefab Builder 和正式 `DetailsPanel.prefab` 页签/页面绑定；保持原三页索引、按钮、关闭、模态及暂停行为。
- 扩展详情快照，条目包含内部稳定 ID、解锁态，以及仅解锁时才提供的标题和正文。占位/无运行时数据源不得默认开放内容。
- 阅读视图只负责选择、呈现与滚动；不持有 NarrativeRuntime、不播放/结算事件、不改存档。
- 不创建新 Scene、Canvas 或输入系统。使用 `Assets/Scenes/PresentationDebugScene.unity` 和现有详情面板 PlayMode 测试回归。

## 验收

- 原三页、关闭和地图输入恢复不回归；新页签可切换，暂停时可交互。
- 多页根事件在列表只占一项，正文顺序正确且可滚动。
- 未解锁、明确锁定、诊断失败和无运行时数据中，不出现标题、ID、正文、摘要、日期、路线或搜索/悬停泄露。
- 已发生、活动/排队、Immediate 可请求、MapAction 可请求的事件正确解锁；无法预检的入口默认锁定。
- 刷新不推进剧情、不执行 NCS Result、不改快照或存档。
- 在共享 `PresentationDebugScene.unity` 回归，并为新门禁和内容合并补充测试。

## 已知取舍

解锁根事件会开放其所有分支与后续页，可能包含玩家尚未走到的文本。现有系统没有逐页历史，本功能不擅自添加该事实。若将来要求严格只显示实际读过的分支，需先在既有 NCS 体系中定义正式逐页完成事实。
