## 打开与查找

1. 打开 `Assets/Scenes/PresentationDebugScene.unity`，进入 Play，按 `~`，左侧选择「叙事调试」。也可在其他场景浏览配置及诊断。
2. 在「内容查找」输入中文标题、事件 ID、演出 key、源行 ID 或正文，点击搜索。结果每页 8 条，类型区分 Event、Opening、Conversation 等。Conversation 按源段落列出，保留多事件引用。
3. 选择 Event 可查看关联演出；选择 Opening 或 Conversation 后在「播放控制」进行预览。其他类型仍可检索，不能假装可转成对话预览。
4. 重载读取已经生成的 Luban 数据；活动预览或测试期间拒绝重载。删除的选择保留失效提示。

## 只看演出

- 「从头播放 / 重播本段」只播放选中的演出段落，不执行 NCS 结果。
- 输入本段 **0 起始快照行索引** 后点击「定位指定句」，或使用上一句/下一句。索引不等于源行 ID / seq；复制诊断包含二者。
- 定位通过 `DialogueScript.RebuildAt` 重建目标前人物与表情状态，背景沿脚本设置，Conversation 段落的 BGM 会重新应用。跳过句的音效不逐句播放。
- 「到下一组选项」跳到本段末句、补全文字后进入选项，不自动选择。纯演出选项禁用，并提示改用分支测试。
- 文字速度、逐字开关应用到下一次播放/定位。GM 自动关闭便于观看，按 `~` 可再次暂停并查看定位。
- 「停止预览」停止自己的对话舞台；「退出测试会话」同时销毁测试 presenter、内存会话并释放模拟暂停。

## 真实分支测试

1. 查找并选择 **Event**，到「测试条件」设置四项属性（language/courage/wisdom/perception）、日期、地点、配置中的 Bar 与布尔条件，必要时准备已有事件 ID 的发生事实。
2. 每项填写后点其「应用」。core 在上一轮结束后的首次修改时恢复起点；同轮多项修改可累积。前置事实不结算其奖励。
3. 点击「建立测试起点」，再「直接请求选中事件」。该操作通过真实 Controller 请求事件，使用 NarrativePresenter 调度真实演出、页条件和选项。Conversation 经正式适配器在 DialoguePanel 显示，选项进入独立核心的真实校验。
4. 检定由独立会话的真实属性读取器计算；不是 GM 指定成功/失败。可用实际配置 `first_day_perception` / `arrival.perception` 相关事件，分别设 perception=2 与 3，观察实际路径。
5. 在「状态与诊断」查看检定当前值/门槛、选择、结果变化、队列、事件事实及宿主请求。使用「复制定位信息」复制纯文本。
6. 使用「恢复测试起点并重测事件」测试同一起点；要改条件，先恢复，修改后重新建立起点。恢复会销毁旧演出并使旧回调失效。
7. 「自然日期提交」「自然阈值提交」「结束测试回合」是独立调度操作，和直接请求分开。日志记录提交动作及变化；直接请求成功不代表自然触发验收通过。

测试只使用独立内存 Provider / Inventory / Action 状态；不会替换 NarrativeRuntime.Instance。正式事件忙或其他对话占用舞台时拒绝测试，保留选择。安全边界启动后持有 PresentationPauseRegistry 令牌；退出释放本测试的令牌。

## 已知限制与验收重点

- 1920×1080 的共享场景和 GM「叙事调试」首屏已实际截图查看；窄窗口滚动/输入区、正式开场 I01、GM 完整 B01–B08 手动流程尚未逐项执行。
- 外部命令产生的镜头、持续遮罩状态不在 DialogueScript 的逐句模型内，定位不能恢复这部分未提供的状态。静态背景、人物/表情及目标句显式效果使用现有模型。
- 纯演出当前到本段下一组选项，不能自动跨段推断未经核心判定的分支；需选择下一段或进入分支测试。
- 非 Conversation 的 NarrativePresenter A_WAIT 与宿主暂停嵌套已通过专项 PlayMode 测试；其他原子效果及全部宿主交互未逐项人工验收。
- 测试结果中的实际宿主副作用不执行，日志明确区分数值验证和仅记录宿主请求。缺少宿主依赖不等于验证成功。
- “停止预览”不等于完成测试事件；活动分支应恢复起点或退出测试后重测，不能用停止来结算。
