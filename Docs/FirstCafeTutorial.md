# 首日咖啡馆教程与地图生命周期

## 正式流程

1. 新游戏完成既有开场演出后进入 `Map`。首日教程完成前，地图只允许进入咖啡馆。
2. 进入 `CoffeeShop` 后播放既有 NCS 开场和首位客人对话。此时店铺未营业，但大厅中已有教程客人及一张黑咖啡订单；不会扣耐心、触发营业计时或补充普通客人。
3. 对话结束提示点击「工作台」。只有工作台入口可推进教程；不能提前营业。
4. 播放配表中的 `make_coffee_base` 提示，然后复用现有操作指引：拖豆、研磨、取粉、加水、加热、取杯、倾倒、将黑咖啡拖入交付区。
5. 放入托盘不等于完成。必须点击交付区按铃或 HUD 的「交付」，成功交给首位客人才结束教程。空杯、其他饮品或杯子不在交付区时不结算，也不消耗杯子与订单。
6. 教程订单不计入正式营业收入、声望和服务统计。完成后保留真实制作消耗，解除地图目的地限制；玩家回到大厅手动点击营业立牌，才开始正常营业。

## 地图与覆盖界面

- 从地图进入咖啡馆使用 additive 加载；`Map` 不卸载。
- 离开主地图进入其他场景时隐藏常驻地图面板并关闭其场景相机；不会因为保留场景而留下全屏地图遮住咖啡馆。主地图本身不是可关闭的咖啡馆覆盖层，按 M 不会把主界面关成空白。
- 咖啡馆中打开地图只显示同一个 `MapSceneController` 面板，将 Canvas 提升至 `short.MaxValue`，不重建咖啡馆或禁用其脚本。
- 返回同一咖啡馆只收起地图，保留场景对象、工作台状态与教程进度。选择不同玩法场景时才卸载旧玩法场景，始终保留 `Map`。
- 切回已加载的玩法场景时，通过 `IGameplayScenePanelRegistration` 重新绑定该场景的面板入口，不依赖重新触发 `Awake`。新玩法场景可沿用此接口，避免仍打开上一个场景的地图/HUD。
- 地图场景不存在时才补充 additive 加载，并播放短转场。
- 教程对话、工作台指引期间也可打开地图；正式教程未完成时仍只允许咖啡馆目的地。
- 地图、详情、咖啡谱、暂停或 GM 面板覆盖时，工作台指引暂时隐藏，正式教程模拟暂停，不销毁教程或重置已完成步骤。关闭后继续。
- 详情页入口不以教程/对话状态作为拒绝条件；打开详情时收起地图，避免最高地图层挡住详情。
- 覆盖层顺序为地图 `32767`、详情 `32766`、GM `32760`、操作指引 `32000`；详情在暂停时也可切页和关闭。从详情重新打开地图会先关闭详情，避免隐藏的详情锁住地图导航。
- 正式教程中禁用跳步换杯、丢弃、清空设备和离开工作台。交付阶段可使用已有重试按钮重做，避免饮品出错后卡死；重试不完成教程。

## GM 与边界

- GM「咖啡馆教程」→「直接进入咖啡店经营」跳过正式教程和第一位客人的多余对话，取消待执行提示/引导，清理教程客人与订单，恢复准备营业状态。
- GM 的黑咖啡/精粹炉练习仍是独立可恢复练习，不能覆盖正在执行的正式教程，也不提交教程订单。
- NCS 文本、感知检定与结果继续使用原有配置；`CafeTutorialSession` 只维护工作台与实际交付信号的顺序，不承担剧情结算。
- 正式教程期间保持原有不可存档边界；教程订单的领域快照校验只放行其指定 ID、客人、黑咖啡餐品及未营业准备阶段组合。

## 回归入口

- EditMode：`CafeTutorialContentTests`、`FreeCafePeopleTests`、`FreeCafeTutorialRecipeTests`。
- PlayMode：`FreeCafeHudPlayModeTests.FirstCafeTutorialRequiresWorkstationAndRealBlackCoffeeDeliveryBeforeManualOpening`，复用 `CoffeeShop`，验证工作台可进入、覆盖界面不结束教程、托盘不提前完成及真实交付后手动营业。
- PlayMode：同类中的 `MapOverlayReusesTheSceneAndKeepsCafeObjectsAndScriptsAlive` 验证补加载地图、最高层级、重复打开复用场景与面板、返回原店时对象与脚本仍在；`GmSkipCancelsOfficialGuidanceAndRestoresPreparationWithoutTheFirstCustomer` 验证中途跳过的清理与营业解锁。
- 演出 UI 仍使用共享 `Assets/Scenes/PresentationDebugScene.unity`，不创建临时场景。
- 共享场景中的 `DetailsPanelTests.DetailsRemainsAboveTutorialAndGmAndWorksWhilePaused` 覆盖详情层级与零时间缩放下的切页/关闭。
- 手动检查：首位客人对话、磨豆、加热、倾倒及待交付期间分别打开/关闭地图；返回原店后检查对象和进度未变，再完成按铃交付。
- 手动检查：教程各阶段打开详情页并切换分页；从 GM 跳过后无残留提示、订单或输入锁，并可正常点击营业立牌。
