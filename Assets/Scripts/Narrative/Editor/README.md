# Narrative Luban Editor

Author `Assets/ConfigTables/Data/Narrative.xlsx` using standard Luban sheets. `Assets/游戏叙事控制系统.xlsx` remains design documentation, not an import source. Preserve the first four rows: `##var`, `##type`, `##group`, `##` descriptions; data begins at row 5 with column A reserved for the marker. Text belongs exclusively to shared `Assets/ConfigTables/Data/Text.xlsx`.

`Spotlight/Narrative/Generate Luban` runs `Assets/ConfigTables/GenerateAll.bat`. A successful exit imports generated JSON and runs business validation; failure reports its exit code. The pipeline outputs cs-json: C# in `Assets/Scripts/Config/Generated`, JSON in `Assets/Settings/Resources/Luban`. The same GenerateAll entry regenerates shared text. Allow generated C# compilation/import to finish before validating schema changes. `Spotlight/Narrative/Validate Luban` calls `LubanNarrativeLoader.Load()` and `NarrativeConfigurationValidator.Validate()`. No custom XLSX reader or ScriptableObject creation/persistence remains.

Validation preserves duplicate ID, ownership, cross-table, relation target, threshold, setup/template slot, derived cycle/source/weight and range rules (`0..20`, `0..10`, `-2..5`, with only `world.calendar` exempt). Weekly empty/zero day normalizes to 1; yearly dates require `1..365`. Trigger onceType and event onceOnly are separate; rows sharing `(barKey, threshold, direction)` must agree on resetOnExit. PLAY_SETUP cannot invoke a nonempty choice transaction; choices require an active narrative event. Generated record ordering is retained; EventDate rowIndex is zero-based generated data order, not an Excel address.

`EventByBar and Anchors` loads ordinary configuration from Luban, with explicit Reload. Anchor status is derived, never an editable column: no event condition and every trigger path enabled/upward/monotonic with a positive step; ungated date-only events also qualify. Validation logs report count/ratio and warn at zero or above 40% without writing metadata.

Reverse suggestions copy separate Bar or Trigger tab-separated data rows to the clipboard only. Output includes empty column A and no headers; paste into the corresponding sheet data area, row 5 onward. Nothing writes a workbook or SO in the background. Review IDs, relation endpoints, derived sources and event onceOnly; reverse triggers still reference the same event and cannot bypass its lifetime lock. Add both row sets before generating. Bar output includes autoStep as its final field.

Editor tests cover actual generated Luban loading, business validation, anchors, invalid effects, shared reset rules, choice transaction rejection and nonmutating clipboard row shape. XLSX reader and SO persistence tests have been removed. Compilation and test execution belong to the supervising task.
